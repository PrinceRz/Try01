2.git branch (<xxx>)

3.git checkout <xxx> (-b <xxx>)
切换到分支 / 一步新建并切换

4.git merge <xxx>
合并, 把xxx合并到当前所在的分支

5.git rebase <主>
并行变线性顺序, 当前移到主后面

6.git checkout HEAD
指向最近提交, 决定父结点

7.git checkout main^ / HEAD~3, 
相对引用, 向上移动到父节点, 只能动HEAD! 

8.git branch -f main HEAD~4
强制main分支移动到上面几次
